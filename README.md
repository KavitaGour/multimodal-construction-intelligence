# 🏗️ Multimodal Construction Intelligence Platform

> Skill Wallet Capstone Project 1 — an AI-powered construction dashboard built with **Streamlit** and **Google Gemini**.
> Runs fully offline in **Demo Mode** (no API key needed) and switches to live AI when a Gemini key is supplied.

## Project Overview

The platform analyses construction-site photos for PPE compliance, diagnoses concrete/wall cracks, estimates project
budgets and asset values in INR, generates weather-aware safety advisories, and offers an interactive construction
assistant. All AI output is converted into validated, predictable JSON before it is displayed or downloaded.

## Problem Statement

Site safety audits, structural defect triage and early-stage project estimation are slow, manual and inconsistent.
Small teams often lack instant access to a safety officer or structural engineer for first-level guidance.
This project shows how multimodal AI can provide a fast, structured **first-pass** assessment — while being explicit
that it never replaces professional inspection.

## Objectives

1. Detect PPE (helmet, hi-vis vest, steel-toe boots, harness) and hazards from site images.
2. Classify visible cracks and recommend repair approaches.
3. Estimate budget, CapEx, asset value, steel and cement for a project (INR, Lakh/Crore).
4. Provide weather-based safety advisories and daily checklists.
5. Provide a construction chatbot that works with or without an API key.
6. Guarantee robust JSON contracts, graceful error handling and a fully functional Demo Mode.

## Features

| Module | What it does |
|---|---|
| **Site Safety & PPE Audit** | Upload JPG/PNG → safety score gauge, PPE checklist with confidence bars, hazard cards with severity badges, recommendations, JSON download |
| **Crack Diagnostics** | Classifies Hairline / Settlement / Structural Shear / Thermal Expansion / Spalling, width estimate, causes, repairs (e.g. epoxy injection, structural re-grouting), urgency, confidence, JSON download |
| **Planning & Valuation** | Structure type, area, location tier, quality, completion slider → budget, CapEx, asset valuation, steel & cement, milestone tracker, charts, JSON download |
| **AI Rendering Prompt** | Builds a detailed text-to-image architectural prompt (optional Gemini refinement). No image API required |
| **Daily Site Assistant** | Weather advisory (Normal / High Wind / Heavy Rain / Extreme Heat) with alerts, actions, prohibited activities, checklist + Engineering chatbot |
| **Consolidated Report** | One JSON + Markdown report combining everything done in the session |
| **Demo Mode** | Every feature works with no key; all demo output is labelled *"Demonstration result — not generated by live AI."* |

## Technology Stack

Python 3.9+ · Streamlit · Google Gemini API (`google-genai`) · Pillow · Pandas · Plotly · standard library (`json`, `hashlib`, `re`…).
No database — state lives in `st.session_state`.

## System Architecture

```
                ┌──────────────────────────── Streamlit UI (app.py) ───────────────────────────┐
 Sidebar:       │ Overview │ PPE Audit │ Crack Diagnostics │ Planning & Valuation │ Assistant │ Report │
 key, mode,     └───────┬──────────┬───────────────┬────────────────┬──────────────────┬───────┘
 navigation             │          │               │                │                  │
                 safety_analysis  crack_analysis  valuation   weather_advisor + construction_assistant
                        │          │               │ (rule-based)     │ (KB in demo / Gemini live)
                        └────┬─────┘               │                  │
                       gemini_service  ──►  Google Gemini API   (absent key ⇒ Demo Mode data)
                             │
                      utils/json_utils: extract → repair → validate → coerce  ──► strict JSON contracts
                             │
                      report_generator ──► JSON / Markdown downloads
```

**Request flow (image analysis):** upload → `image_utils.load_image` validates → `analyze_*` → (live) Gemini JSON
→ `parse_json_safely` → `validate_*` → stored in session state → rendered + downloadable.
Any failure at any step falls back to clearly-labelled demo data instead of crashing.

## Demo Mode

* Activates automatically when no key is configured (or Gemini is unreachable / returns unusable output).
* Uploads are validated and previewed, **but the image is not analysed**: one of several built-in sample scenarios is
  chosen deterministically from the file bytes so results are repeatable.
* Every demo result carries `meta.mode = "demo"` and the text *"Demonstration result — not generated by live AI."*
  in the UI, the downloaded JSON, and chatbot replies.
* Valuation, weather advisories and the rendering prompt are formula/rule-based and work identically in both modes.

## Gemini API Configuration

1. Create a key at https://aistudio.google.com/apikey.
2. Choose **one**:
   * **Sidebar:** paste the key → *Connect Gemini* (the key is verified, held in memory only and never shown again).
   * **Environment:** `export GEMINI_API_KEY="..."` (Windows PowerShell: `$env:GEMINI_API_KEY="..."`).
   * **`.env` file:** copy `.env.example` → `.env`, fill in the key.
   * **Streamlit secrets:** copy `.streamlit/secrets.toml.example` → `.streamlit/secrets.toml`.
3. The model name is set in `config.py` (`DEFAULT_GEMINI_MODEL = "gemini-2.5-flash"`). Change it if your account uses another model.

## How Each Module Works

* **PPE Audit** – sends the image + a strict JSON prompt (OSHA PPE/fall-protection and IS 456 context). The reply is
  repaired/validated: score clamped to 0-100, statuses ∈ {Detected, Not Detected, Unclear}, severities ∈ {Low, Medium, High, Critical}.
  The prompt instructs Gemini never to invent detections (unseen items → "Unclear" with low confidence).
* **Crack Diagnostics** – same pipeline with the defect contract; width is flagged as a rough visual estimate.
* **Planning & Valuation** – `valuation.py` holds editable rate tables (₹/sq ft by type, tier, quality; steel kg/sq ft; cement bags/sq ft).
  Budget = area × cost rate; CapEx = budget × completion; valuation = completed market value × completion. Results are *conceptual*.
* **Weather Advisor** – a curated rule-based library (not a live weather feed) with alerts, actions, prohibited activities and a tick-able checklist.
* **Assistant** – live: Gemini with session context (latest audits, weather, project); demo: keyword knowledge base for rain, wind, heat, pre-pour checks, curing, cracks, PPE, excavation, scaffolds, reinforcement, mix quality, electrical.
* **Reports** – `report_generator.py` merges all session results into JSON + Markdown.

## JSON Output

PPE audit contract (crack and valuation contracts are in `crack_analysis.py` / `valuation.py`):

```json
{
  "meta": {"mode": "demo", "demo_notice": "Demonstration result — not generated by live AI.", "...": "..."},
  "analysis": {
    "safety_score": 82,
    "overall_status": "Compliant",
    "ppe_detection": {
      "helmet": {"status": "Detected", "confidence": 94},
      "high_visibility_vest": {"status": "Detected", "confidence": 91},
      "steel_toe_boots": {"status": "Unclear", "confidence": 52},
      "safety_harness": {"status": "Not Detected", "confidence": 71}
    },
    "hazards": [{"hazard": "", "severity": "High", "description": "", "corrective_action": ""}],
    "recommendations": []
  }
}
```

Malformed model output is handled in four steps: **extract** the `{...}` block → **repair** (trailing commas, `True/None`,
smart quotes, truncation) → **retry once** with a stricter prompt → **validate/coerce** every field; if all fails the app falls back to demo data.

## Deployment to Streamlit Community Cloud

**1. Push to GitHub**

```bash
cd multimodal-construction-intelligence
git init
git add .
git status                      # confirm .env / secrets.toml are NOT listed
git commit -m "Multimodal Construction Intelligence Platform"
git branch -M main
git remote add origin https://github.com/<your-username>/multimodal-construction-intelligence.git
git push -u origin main
```
(Create the empty repository on github.com first: **New repository** → no README/.gitignore → Create.)

**2. Deploy**

1. Go to https://share.streamlit.io and sign in with GitHub (authorise access to your repository).
2. Click **Create app** → **Deploy a public app from GitHub**.
3. Choose your repository, branch **main**, and main file path **`app.py`**.
4. Open **Advanced settings** → **Secrets** and paste:
   ```toml
   GEMINI_API_KEY = "your-real-key"
   ```
   (Skip this to deploy in Demo Mode. Python 3.10+ is recommended in Advanced settings.)
5. Click **Deploy** and wait for the build to finish.
6. Open the generated `https://<your-app>.streamlit.app` URL and verify it is served over **HTTPS**, shows the correct
   mode (Demo or Live) in the sidebar, and that each page loads.

## Limitations

* AI results are an **initial, visual, AI-assisted assessment** — not a safety certification, audit, or structural engineering report.
* Crack width from a single photo without a scale reference is only approximate.
* Valuation figures are **conceptual**; rate tables are simplified and not tied to any city's live market; land cost is excluded.
* The weather advisory is a curated rule set; it does not fetch live weather data.
* No image generation: only a prompt is produced.
* Session state is temporary — refreshing the page clears results (download your JSON reports).
* Gemini model names change over time; adjust `DEFAULT_GEMINI_MODEL` if needed.
